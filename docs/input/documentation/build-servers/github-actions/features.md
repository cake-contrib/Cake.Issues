The [Cake.Issues.BuildServer.GitHubActions addin] creates annotations from issues when running on
GitHub Actions.

![Pull request integration](githubactions-pullrequest-integration.png "Pull request integration")

## Features

* [x] Reports issues as annotations to GitHub Actions builds.
* [x] Group issues in log output by provider and run information.

[Cake.Issues.BuildServer.GitHubActions addin]: https://cakebuild.net/extensions/cake-issues-buildserver-githubactions/
